# 变量与类型

Python 是动态类型语言，变量无需声明类型。

## 基本类型

```python
name = "Alice"        # str 字符串
age = 25              # int 整数
height = 1.75         # float 浮点数
is_student = True     # bool 布尔
```

## 类型转换

```python
num = int("100")      # 字符串转整数
text = str(3.14)      # 数字转字符串
```

## 类型判断

```python
print(type(name))     # <class 'str'>
```
