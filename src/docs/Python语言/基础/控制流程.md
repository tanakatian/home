# 控制流程

控制流程决定程序的执行顺序。

## 条件语句

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

## 循环语句

```python
for i in range(5):
    print(i)

while score < 100:
    score += 5
```

## 列表推导式

```python
squares = [x * x for x in range(10)]
```
