# 神经网络基础

神经网络由多个神经元组成，通过层层传递学习复杂特征。

## 神经元结构

每个神经元执行加权求和后，经过激活函数输出：

$$ a = \sigma\left(\sum_i w_i x_i + b\right) $$

## 常见激活函数

| 函数 | 公式 | 特点 |
| ---- | ---- | ---- |
| Sigmoid | $\frac{1}{1+e^{-x}}$ | 输出 0~1 |
| ReLU | $\max(0, x)$ | 计算简单 |
| Tanh | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | 输出 -1~1 |

## 训练流程

1. 前向传播计算输出
2. 计算损失
3. 反向传播更新权重
4. 重复以上步骤
