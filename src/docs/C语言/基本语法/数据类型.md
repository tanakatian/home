# 数据类型

C 语言提供了丰富的数据类型，用于存储不同类型的数据。

## 基本数据类型

| 类型 | 关键字 | 字节数 | 范围 |
| ---- | ------ | ------ | ---- |
| 字符型 | `char` | 1 | -128 ~ 127 |
| 整型 | `int` | 4 | -2^31 ~ 2^31-1 |
| 单精度浮点型 | `float` | 4 | 约 6 位有效数字 |
| 双精度浮点型 | `double` | 8 | 约 15 位有效数字 |

## 示例代码

```c
#include <stdio.h>

int main(void) {
    int age = 18;
    double height = 1.75;
    char grade = 'A';

    printf("年龄：%d\n", age);
    printf("身高：%.2f\n", height);
    printf("等级：%c\n", grade);
    return 0;
}
```

> 提示：不同平台下某些类型的字节数可能不同，可以使用 `sizeof` 运算符查看。

## 小结

- 整型用于存储整数
- 浮点型用于存储小数
- 字符型用于存储单个字符
