# 线性回归

线性回归是最基础的监督学习算法，用于拟合变量之间的线性关系。

## 数学形式

$$ y = w \cdot x + b $$

其中：
- `w` 是权重（斜率）
- `b` 是偏置（截距）

## 损失函数

常用均方误差（MSE）：

$$ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$

## 示例代码

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

## 应用场景

- 房价预测
- 销量预测
- 趋势分析
