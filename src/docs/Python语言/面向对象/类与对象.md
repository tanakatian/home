# 类与对象

类是对象的模板，封装了数据和行为。

## 定义类

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"你好，我是 {self.name}")
```

## 创建对象

```python
p = Person("Alice", 25)
p.greet()
```

## 继承

```python
class Student(Person):
    def __init__(self, name, age, school):
        super().__init__(name, age)
        self.school = school
```
