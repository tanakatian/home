# 运算符与表达式

运算符用于对数据进行运算，表达式由运算符和操作数组成。

## 算术运算符

| 运算符 | 含义 |
| ------ | ---- |
| `+` | 加法 |
| `-` | 减法 |
| `*` | 乘法 |
| `/` | 除法 |
| `%` | 取余 |

## 关系运算符

- `==` 等于
- `!=` 不等于
- `>` 大于
- `<` 小于

## 逻辑运算符

- `&&` 逻辑与
- `||` 逻辑或
- `!` 逻辑非

```c
int a = 10;
int b = 3;
int sum = a + b;   // 13
int mod = a % b;   // 1
int flag = (a > b) && (a > 0);  // 1
```
