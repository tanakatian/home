# 指针与数组

数组名可以被视为指向首元素的指针。

## 等价关系

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;       // p 指向 arr[0]

// 以下三种写法等价
int x = arr[2];
int y = *(arr + 2);
int z = p[2];
```

## 指针运算

- `p++` 指向下一个元素
- `p + n` 指向第 n 个元素

## 遍历数组

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", *(p + i));
}
```
